# البناء من المصدر

بناء الحزمة مستقل عن مجلد اللعبة. **لا تحتاج إلى نسخة من ملفات اللعبة لبناء المثبت**؛ يحتاج المستخدم إلى نسخته المحلية عند التثبيت لتطبيق الترجمة والتعديلات عليها.

## المتطلبات

- Windows 10 أو أحدث مع Windows PowerShell 5.1 و.NET Framework، لتجميع المثبت.
- Python 3.10 أو أحدث مع الحزم المحددة في `requirements.txt`، لتجهيز النصوص وتوليد الخطوط.
- مصدر الخط `fonts/source/IBMPlexSansArabic-Regular.ttf` ورخصته `fonts/source/OFL.txt`.

## الأوامر

من مجلد المستودع:

```powershell
python -m pip install -r requirements.txt
.\build.ps1
```

إذا منعت سياسة التشغيل المحلية السكربت:

```powershell
PowerShell -ExecutionPolicy Bypass -File .\build.ps1
```

يحضر `build.ps1` حزمة البيانات عبر `tools/build_payload.py`، ويعيد إنشاء `build/payload.zip` (وتوضع نسخة داخل `data/` في الحزمة اليدوية)، ثم يجمع واجهة المثبت باستخدام مترجم C# المتاح مع .NET Framework. راجع مخرجات الأمر لمعرفة مواقع ملفات الإصدار الناتجة.

## مسار المحتوى

| المصدر | دوره |
| :--- | :--- |
| `localization/arabic.json` | 5,008 سجلات بالعربية المنطقية، قبل تحويلها إلى ترتيب العرض. |
| `tools/export_text.py` | تجهيز النصوص وصياغتها في ترتيب العرض المطلوب للمحرك. |
| `fonts/build_fonts.py` | توليد الخطوط والأطالس من مصدر IBM Plex Sans Arabic. |
| `tools/build_payload.py` | تجهيز حزمة البيانات التي يستخدمها المثبت. |
| `installer/InstallerEngine.cs` | محرك مشترك يطبق الترجمة على XML الأصلي للمستخدم، ويثبت الخطوط والإصلاح التنفيذي، ويدير النسخ الاحتياطي والإزالة. |
| `build.ps1` | تنسيق البناء وتجميع المثبت. |

لا تحفظ النصوص العربية المعكوسة أو أشكال العرض الجاهزة داخل ملف الترجمة المنطقي. التشكيل الاتجاهي وتجهيز العرض مسؤولية مرحلة التصدير؛ تطبيقهما مرتين يفسد الناتج.

## قبل إصدار نسخة جديدة

1. تحقق من اكتمال السجلات وسلامة الرموز، ومن ثبات المخرجات عند إعادة البناء من المصادر نفسها.
2. تحقق من تحميل الخطوط المولدة ومن عدد المحارف والملفات، ثم راجع ملفات الحزمة للتأكد من خلوها من مسارات شخصية أو ملفات أصلية للعبة.
3. اختبر التثبيت والإزالة على نسخة اختبار، وتأكد أن الإزالة تعيد الحالة السابقة وأن الإصدار التنفيذي غير المدعوم يرفض قبل الكتابة.
4. اختبر العرض داخل اللعبة: ظهور النص تدريجيا، العربية المختلطة بالأرقام والرموز، التفاف السطور، وأحجام الترجمة المختلفة. سجل ما تحقق فعليا وما بقي دون اختبار.
5. حدث أرقام الإصدار وروابط التنزيل و[حالة التوافق](COMPATIBILITY.md)، وأرفق الحزمتين الجاهزتين بصفحة الإصدار.

لا تضع ملفات اللعبة التنفيذية أو ملفات لغتها الأصلية في المستودع أو الحزم. يعتمد التثبيت على بيانات الترجمة والتعديل وعلى ملفات المستخدم المحلية.
